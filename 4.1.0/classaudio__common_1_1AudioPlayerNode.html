Detailed Description

ROS 2 node that subscribes to stamped audio messages and plays them through a PortAudio output device.

One PortAudio stream is opened per unique combination of input sample format, input sample rate, input channel count, output sample rate, and output channel count. Mono/stereo channel conversion and sample-rate conversion are performed automatically when the incoming audio differs from the configured output format.

ROS 2 Parameters
  • channels (int, default 2): Number of output audio channels.
  • rate (int, default 0): Output sample rate. 0 selects the device default output sample rate.
  • device (int, default -1): PortAudio output device index. -1 selects the system default output device.
  • publish_reference (bool, default true): Publish the played frames.
Subscriptions
  • audio (audio_common_msgs/msg/AudioStamped, SensorDataQoS)
Publications
  • played (audio_common_msgs/msg/AudioStamped, SensorDataQoS) when enabled
Note
Topic names are fixed defaults and should be changed with ROS 2 remappings rather than parameters.
